# Generated Review Artifacts

Updated: May 3, 2026

This directory holds generated or semi-generated review files. They are useful operational artifacts, but they are not canonical documentation.

## Files

| File | Producer / Purpose |
|------|--------------------|
| `KitBoxImageMatchDryRun.csv` | Produced by `tools/match_kit_box_images.py`; review candidate kit-box image matches |
| `ScifiKitbashTid33MapImageMatches.csv` | Produced by `tools/link_scifikitbash_tid33_maps.py`; review ScifiKitbash thread 33 map-image matches |
| `PptxLabelKitMatchSuggestions.csv` | PPTX overlay-label to kit-match suggestion review data |
| `PptxLabelKitMatchReview.html` | Browser review UI for PPTX label-kit suggestions |

## Rule

Generated artifacts may be kept when they are useful for review, but current project status belongs in `docs/CurrentStatus.md`, route inventory belongs in `docs/API.md`, and schema summary belongs in `docs/DataModel.md`.
